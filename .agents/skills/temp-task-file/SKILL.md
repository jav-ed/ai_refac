# Temp task file

Only create it if the user tells you to - or you see yourself, okay, this now becomes a lot to recall. If you are working on a task and the user is giving you 3 more tasks - you won't recall them all. So, instead of quitting what you are doing, you take short notes in that file.


The benefits are inshallah: you see the list of tasks and can decide the order of the tasks. You get a nice overview, dont skip tasks, each tasks get the time/effort it needs.

Very important: Do not make that short tasks file a protocoll, no history protcoll, not a investigation file.

- A fresh agent creates its own uniquely named file: `Scratch/Agent_Tasks/<topic>_<unique-id>.md`.
- Never take over another agent's file unless the user explicitly asks. Continue using your own file when resuming your work.
- Reorder tasks as useful, respecting any order the user specifies.
- Add a small file-tree sketch/optimization when it helps you think clearly about the work.
